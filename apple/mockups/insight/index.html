Why a Workflow and not an Agent

The describing job is a fixed sequence: cut, listen, describe, embed, record. No step is chosen by a model. A Cloudflare Workflow gives each step its own retries and remembers the finished ones, so a slow answer from Haiku re-runs the describe step and never the ffmpeg. It also runs outside the one object that serves every request and holds the line. The Agents SDK earns its place later, as a chat that answers "ask my library" and calls the search routes as its tools.

    What this is based on, and what is not verified

    Read the caveats
    • No model has been run on any clip. Every token count here is an estimate (1,200 tokens of instructions, a 450 token answer, 4.3 tokens for each second of speech, half the seconds carrying speech, tall frames). The fix is to count tokens on the real prompt and read the usage the API returns for ten real clips. Nobody has measured the quality of either describer.
    • Pages read on 10 oct 2026. Anthropic's pricing and batch rows were read from the raw page text. The Cloudflare pages were read through a fetch tool that summarises with a small model, so each Cloudflare number is a faithful extract and not a copied table row. Three of them agree with a neuron calculation. Open a source link before money depends on one figure.
    • The Haiku 5.5 price rows were checked directly on Anthropic's pricing page by the parent session on 10 oct 2026: $0.10 in and $0.50 out per million tokens for prompts up to 100,000 tokens, and $0.05 and $0.25 through the Batch API.
    • Haiku takes no video and no audio. It receives sampled frames and a transcript. Whisper on Workers AI makes the transcript.
    • There is no zero-retention path today. Anthropic deletes inputs and outputs within 30 days by default. Zero retention is arranged with Anthropic's sales team per organisation. Cloudflare's own zero-retention routing covers only unified billing, and Haiku 5.5 is not in that catalog yet.
    • Workers AI has no image-embedding model. "Find the frame that looks like this" is not on offer. Scene captions embedded as text cover most of that need.
    • Haiku will not name a person from a face and declines explicit images. The copy never suggests it can name anyone, and a declined post falls back to the Cloudflare describer.
    • "On your bill" assumes room in the free allowances (10,000 neurons a day on Workers AI, the container hours that Workers Paid includes). Nobody checked the account's current usage.
    • ffmpeg timings are guesses. 4 s plus 1.5 s a frame comes from a README sentence about one poster. Nobody timed a run of 24 seeks on the quarter-vCPU instance.
    • The production numbers (172 saves, 162 videos, the five length buckets) were read from D1 on 10 oct 2026 and not queried again. Only the buckets are known, so frames per bucket are estimates: exact for the shortest and longest buckets, an upper bound for the 1 to 3 minute one. The 191 things priced against 172 saves are an upper bound.
    • The phone is a stand-in. It holds 15 sample saves and searches them with a small word and synonym matcher. The real search embeds the query and ranks by nearness. The page checks the default settings against the JSON, and it labels anything else as this page's own arithmetic.
