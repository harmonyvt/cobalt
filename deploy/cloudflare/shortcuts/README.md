# cobalt Shortcuts (macOS)

Two Shortcuts for the private cobalt instance. Both talk only to
`https://api.capybaraharmony.com` with a per-owner API key and are generated by
scripts (no hand-editing the plist):

| Shortcut | Build | What it does |
| --- | --- | --- |
| `cobalt → webp` (`cobalt-webp.shortcut`) | `build.mjs` | Original video into `~/Downloads` **and** an animated webp of the whole video, its URL on the clipboard. |
| `cobalt studio` (`cobalt-studio.shortcut`) | `studio.mjs` | Saves the video behind a link and opens its studio page (pick up to 10 s, render webps there). |

Shared code: `lib.mjs` (plist writer, token strings, If blocks, personal-build
mode). Structural checker: `verify.mjs`. Pinned studio API/web contract:
`../STUDIO-CONTRACT.md`.

## cobalt → webp

1. Takes the share-sheet input (URL, text, Safari page) plus the clipboard in
   one Text; the API takes the first http(s) link in it.
2. **Original first** (tunnel links expire in 90 s): `POST /` `{url}` then
   branch on `status`: `tunnel`/`redirect` download `url`; `picker` downloads
   the first item; `error` shows a notification and the run **continues**. The
   file is saved to `~/Downloads` under the API's `filename`.
3. **WebP of the whole video**: `POST /webp` `{url}` gives
   `{status:"pending", id}`, then `GET /webp/<id>?wait=20` up to 15 times, only
   while still `pending`. `success`: the webp `url` is copied and a "webp link
   copied" notification shows it. `error` or timeout: an alert names the step
   and the error code. (No start/length: the API rejects videos that are too
   long with `error.webp.too_long`.)

## cobalt studio

1. Same input: share-sheet input + newline + clipboard in one Text.
2. `POST /studio` `{url}` -> `{status:"success", id, url}` at once (the API saves
   the video in the background; see the contract).
3. `status` is `success`: **Open URLs** on `url` (the studio page, behind
   Cloudflare Access) and a "studio ready" notification with the url.
   Otherwise: an alert with `error.code`; for `error.studio.no_link` it adds
   "copy a link first" (`error.studio.busy` is shown as the bare code).

No downloads and no polling: the page does the rest.

Every API request sends `Authorization: Api-Key <key>`, `Content-Type` and
`Accept: application/json`. Both shortcuts branch on the JSON `status` only.

## Build

```
# default build: no key inside, import question asks for it
node deploy/cloudflare/shortcuts/build.mjs     # -> cobalt-webp.shortcut
node deploy/cloudflare/shortcuts/studio.mjs    # -> cobalt-studio.shortcut
```

Each writes `<name>.unsigned.shortcut` (git-ignored), checks it
(`verify.mjs`, kind `webp` or `studio`), and signs it with
`shortcuts sign --mode anyone`. Signing needs network access to Apple. The
default files contain no key. Rebuilding `cobalt-webp` is byte-stable
(deterministic UUIDs).

### Personal build (what to actually install)

The v1 import question re-prompted forever on macOS 27, so the personal build
embeds your key and has no import question. The key file is
`{"key": "<lowercase uuid v4>"}` (chmod 600, never in the repo); the output goes
**outside the repo**. Unsigned intermediates go to a private temp dir and are
deleted.

```
export COBALT_SHORTCUT_KEY_FILE=~/.config/cobalt/shortcut-key.json
COBALT_SHORTCUT_OUT=~/Downloads/cobalt-webp.shortcut   node deploy/cloudflare/shortcuts/build.mjs
COBALT_SHORTCUT_OUT=~/Downloads/cobalt-studio.shortcut node deploy/cloudflare/shortcuts/studio.mjs
```

Then double-click the signed file and choose **Add Shortcut**. Debug builds:
`COBALT_SHORTCUT_DEBUG_URL=<url>` uses a fixed Text instead of the clipboard.
The key is the per-owner key created in the web UI (settings → instances → api
keys, shown once). Rotate: create a new key, rebuild, re-import, revoke the old
one. In a default build the **first Text action** holds the key (paste it
there).

Use either shortcut from a page's Share menu, the menu bar (pinned), Spotlight,
or with a link on the clipboard. First run: allow the network domain (and, for
webp, Downloads access).

## Lessons that shaped the builders (macOS 27, 2026-09-30)

Keep these; each one was a broken import or run.

- **If conditions**: `WFConditionalActionString` must be a `WFTextTokenString`
  (`tstr`), not a plain string, **and** the If's input must be coerced to Text
  (an `asText` aggrandizement, `WFCoercionVariableAggrandizement` /
  `WFStringContentItem`). Otherwise the field imports empty ("If Dictionary
  Value is ___") and the run fails with "Please choose a value for each
  parameter in this action". `lib.mjs` does both; `verify.mjs` checks both.
- **Don't use "Get URLs from Input" / "Get Item from List" for the link.** They
  produced an empty string even with a fixed URL. Send the free text; the API
  Worker extracts the first http(s) link. (`picker` responses still use Get
  Item from List; that part only reads a dictionary item.)
- **Don't rely on `WFWorkflowNoInputBehavior`** (imported as "If there's no
  input: Continue"). Combine Shortcut Input + Get Clipboard in one Text action
  instead. Don't branch on "has any value" either.
- **Import questions re-prompted forever**; hence the personal build with the
  key embedded (`COBALT_SHORTCUT_KEY_FILE`, `COBALT_SHORTCUT_OUT`).
- **Open URLs** (`is.workflow.actions.openurl`, studio only): the input is
  `WFInput`, an action-output attachment (Text coerces to URL). This parameter
  name is from the community action reference and has not been confirmed by a
  run on macOS 27 yet. If it imports as "Open URLs: URLs ___", set the input to
  the previous "Dictionary Value" by hand and tell whoever maintains the
  script.

## Troubleshooting

- **Alert with an error code**: the code is the API's `error.code`. Auth-style
  codes or an empty code usually mean a wrong, empty or revoked key. For
  `cobalt studio`: `error.studio.no_link` means no http(s) link was in the
  input or on the clipboard; `error.studio.busy` means a save or encode is
  already running.
- **cobalt → webp: nothing saved / saved to the iCloud Shortcuts folder**: open
  the *Save File* action, make sure "Ask Where to Save" is off and the folder is
  Downloads.
- **The run stops with a Shortcuts error dialog** on a request step: Shortcuts
  cannot catch a failed network fetch. The API's own errors are handled; a
  dropped connection or an expired tunnel link is not.
- **"webp step timed out"**: the job is still running (15 polls x 20 s). Long or
  high-resolution sources can exceed that.
- **Wrong link picked**: only the first http(s) link in the input is used;
  share-sheet input wins over the clipboard.

## Manual build of cobalt studio (fallback, if the import misbehaves)

New shortcut, then add in order:

1. **Text** (your key) → **Set Variable** `apikey`. **Text**
   `https://api.capybaraharmony.com` → **Set Variable** `base`.
2. **Get Clipboard**, then **Text**: *Shortcut Input*, a newline, *Clipboard* →
   **Set Variable** `link`.
3. **Get Contents of URL** `base`/studio, method POST, headers `Authorization`:
   `Api-Key ` + `apikey`, `Content-Type` and `Accept`: `application/json`;
   request body JSON with `url` (Text) = `link`.
4. **Get Dictionary Value** `status` of the result. **If** it *is* `success`
   (make sure the value is a Text and the field says `success`):
   **Get Dictionary Value** `url` → **Open URLs** → **Show Notification**
   "studio ready" + the url.
5. **Otherwise**: **Get Dictionary Value** `error.code` of the POST result;
   **If** it is `error.studio.no_link` → **Show Alert** "cobalt studio" +
   code + ": copy a link first"; **Otherwise** → **Show Alert** with the code;
   **End If**, **End If**.
6. Details: use as Share Sheet / Menu Bar; accept URLs, Text, Articles, Safari
   web pages.
